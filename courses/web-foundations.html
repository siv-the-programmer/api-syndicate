What you'll learn

Before you start

Curriculum

4 weeks · 16 lessons · a hands-on exercise and a deliverable every week.

Week 1How the web works and your first page

Understand what happens when someone opens a website, and write your first HTML page.

  1. 1.1

    How the web works

    Domains, DNS, servers and browsers explained simply. What actually happens between typing a URL and seeing a page.

  2. 1.2

    Setting up your tools

    Install VS Code, a browser with DevTools and the extensions we use every day. Create your project folder.

  3. 1.3

    HTML structure

    Headings, paragraphs, links, images and lists. How to structure a page so browsers, screen readers and Google understand it.

  4. 1.4

    Pages and links

    Build a multi-page site: home, about and contact pages linked together with a shared layout.

Exercise
Recreate a simple business card page from a screenshot using only HTML.
By the end of the week
A three-page HTML site with navigation between the pages.
Week 2Styling with CSS, mobile first

Make your pages look professional on every screen size.

  1. 2.1

    CSS basics

    Selectors, colours, fonts and spacing. How the cascade works and why your styles sometimes don't apply.

  2. 2.2

    The box model

    Margin, border, padding and content. The single idea that explains most layout problems.

  3. 2.3

    Flexbox and Grid

    Modern layout tools for navbars, card grids and page structure, with no floats or hacks.

  4. 2.4

    Mobile-first design

    Design for phones first, then scale up with media queries. Test on real devices with DevTools.

Exercise
Style your three-page site with a colour palette, Google Fonts and a responsive card grid.
By the end of the week
A fully styled, responsive version of your site that looks good on a phone and a laptop.
Week 3JavaScript: making pages interactive

Learn enough JavaScript to add real interactivity to your site.

  1. 3.1

    JavaScript fundamentals

    Variables, types, functions and conditions, written and tested in the browser console.

  2. 3.2

    The DOM

    Select elements on the page, change text and styles, and react to clicks.

  3. 3.3

    Events and forms

    Build a mobile menu, an image gallery and a contact form that checks input before sending.

  4. 3.4

    Working with data

    Arrays and objects. Render a list of projects from data instead of hard-coding them.

Exercise
Add a working mobile menu and a filterable projects section to your site.
By the end of the week
Your site with at least two interactive features built from scratch.
Week 4Git, GitHub and going live

Put your site on the internet the way professional teams do.

  1. 4.1

    Git basics

    Commits, history and undoing mistakes. Why every developer uses version control.

  2. 4.2

    GitHub

    Push your code to GitHub, write a README and keep your work backed up and shareable.

  3. 4.3

    Deploying on Vercel

    Connect your repo and deploy. Every push goes live automatically.

  4. 4.4

    Custom domains and launch checklist

    Connect a .co.za or .com domain, add a favicon and meta tags, and run a final check for speed and SEO.

Exercise
Make a change, push it, and watch it deploy automatically.
By the end of the week
Your portfolio site live on your own domain, with the code on GitHub.

Final project

Build and launch your personal portfolio site: at least three pages, fully responsive, with interactive features, deployed on Vercel with a custom domain. You present it in the final live session.
