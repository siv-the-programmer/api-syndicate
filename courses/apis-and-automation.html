Curriculum

6 weeks · 18 lessons · a hands-on exercise and a deliverable every week.

Week 1What an API is

Read API documentation and make requests with confidence.

  1. 1.1

    Requests and responses

    HTTP methods, status codes, headers and JSON, explained with real examples.

  2. 1.2

    Calling APIs

    Use fetch and an API client to get live data from public APIs.

  3. 1.3

    Authentication

    API keys, tokens and OAuth. How to keep keys secret.

Exercise
Build a script that pulls the load-shedding schedule or the weather for Cape Town and prints a summary.
By the end of the week
A small Node.js script that calls two different APIs and combines the results.
Week 2Building your own API

Create an API other software can use.

  1. 2.1

    Node.js and Express

    Set up a server with routes, handle requests and send JSON responses.

  2. 2.2

    Data and validation

    Store data in a database, validate input and return helpful errors.

  3. 2.3

    Deploying an API

    Put your API online and test it from anywhere.

Exercise
Build an API for a small shop: products, stock and orders.
By the end of the week
A deployed API with at least four endpoints and a short README showing how to use it.
Week 3Webhooks

Run code the moment something happens elsewhere.

  1. 3.1

    How webhooks work

    The difference between asking for updates and being told about them.

  2. 3.2

    Receiving webhooks safely

    Verify signatures, handle retries and avoid processing the same event twice.

  3. 3.3

    Real integrations

    Payment, form and GitHub webhooks triggering your own code.

Exercise
When a form is submitted, save it and send yourself an instant notification.
By the end of the week
A webhook receiver connected to a real service.
Week 4Chat bots

Build bots people can talk to.

  1. 4.1

    Telegram bots

    Create a bot, handle commands and reply with buttons and menus.

  2. 4.2

    WhatsApp Business API

    How WhatsApp automation works, message templates, and the rules you need to follow.

  3. 4.3

    Conversation design

    Keep bots short, useful and clear about what they can't do.

Exercise
Build a bot that answers FAQs and takes simple bookings or orders.
By the end of the week
A working bot that stores what users send it.
Week 5Scheduling and notifications

Automate work that happens on a timetable.

  1. 5.1

    Cron jobs

    Run code every hour, every morning or every Friday, reliably.

  2. 5.2

    Email and messaging

    Send transactional emails and messages without landing in spam.

  3. 5.3

    Error handling and logs

    Know when an automation fails, and make it retry safely.

Exercise
Send an automatic daily summary of yesterday's orders.
By the end of the week
A scheduled job running in production with alerts when it fails.
Week 6Automate a real workflow

Put everything together for a real business.

  1. 6.1

    Finding what to automate

    Spot repetitive tasks worth automating and estimate the time saved.

  2. 6.2

    Planning the flow

    Map triggers, steps and failure points before writing code.

  3. 6.3

    Handover

    Document your automation so a business owner can trust it.

Exercise
Interview a business owner and choose one workflow to automate.
By the end of the week
Your final project, live and documented.

Final project

Automate a real workflow for a real business, using a bot, an API and at least one scheduled job or webhook. Examples: booking reminders for a salon, stock alerts for a shop, or lead capture for a contractor. You present the before-and-after time saved.
